01 SAÉ 5 · Alternance

Mise en place d'une solution de supervision réseau avec Zabbix

Déploiement d'une infrastructure de monitoring centralisée à La Station Animation permettant de superviser en temps réel les serveurs (CPU, mémoire, disque) et d'envoyer des alertes automatiques par e-mail lors de dépassements de seuils.

Zabbix 7.0 Debian 12 MariaDB Apache2 Hyper-V SMTP Supervision
Voir le détail ↓ Fév. 2025 · La Station Animation

Contexte & problématique

  • Parc hétérogène : serveurs Windows, postes clients, équipements réseau
  • Aucun système de monitoring unifié → détection tardive des incidents
  • Objectif : détecter automatiquement les pannes et réduire les temps d'arrêt

Ce que j'ai réalisé

  • Déploiement VM Debian 12 sous Hyper-V (4 Go RAM, 2 vCPU)
  • Installation Zabbix Server 7.0 + MariaDB + Apache2/PHP
  • Déploiement agents sur serveurs AJAR, EVA, GARY, PITT, NAS, Gestion
  • Configuration alertes e-mail via SMTP Gmail (port 587)
  • Création triggers CPU >60%, Mémoire >85%, Disque <15%
  • Tableaux de bord de supervision personnalisés

Résultats obtenus

  • Supervision centralisée de 6 serveurs critiques
  • Alertes e-mail fonctionnelles et testées (commande stress)
  • Dashboards avec graphiques historiques CPU/RAM/Disque
  • Export CSV des logs d'incidents

Difficultés & solutions

  • Dépôt Zabbix absent de Debian par défaut → ajout dépôt officiel manuellement
  • Configuration SMTP Gmail → utilisation mot de passe d'application
  • Agents Windows → règles pare-feu à ajouter manuellement
  • Tests triggers → utilisation commande stress --cpu 8
// Analyse réflexive

Ce projet m'a permis de comprendre concrètement les enjeux de la supervision dans un environnement de production réel. J'ai dû adapter mes choix techniques aux contraintes budgétaires de l'entreprise (solution open source), gérer une infrastructure hétérogène (Windows/Linux) et documenter chaque étape de manière professionnelle. La mise en place des triggers m'a appris à anticiper les incidents plutôt que de les subir.

02 SAÉ 5 · Projet tuteuré

Mise en place d'un système de sauvegarde automatisé avec Ansible

Automatisation des sauvegardes d'infrastructure via des playbooks Ansible, permettant de garantir la continuité de service et la récupération rapide en cas de panne.

Ansible Bash Linux Automatisation Sauvegarde Cron
Voir le détail ↓ 2024–2025 · IUT de Roanne

Contexte & objectifs

  • Besoin d'automatiser les sauvegardes sur un parc de machines Linux
  • Réduire les interventions manuelles répétitives
  • Garantir la cohérence et la régularité des sauvegardes

Ce que j'ai réalisé

  • Écriture de playbooks Ansible pour automatiser les sauvegardes
  • Scripts Bash pour la compression et rotation des archives
  • Planification via Cron pour déclenchement automatique
  • Tests de restauration pour valider l'intégrité des sauvegardes

Résultats obtenus

  • Sauvegardes automatisées sans intervention manuelle
  • Rotation des archives paramétrée (conservation 30 jours)
  • Documentation des playbooks pour la maintenabilité

Difficultés & solutions

  • Gestion des droits sudo dans Ansible → configuration sudoers adaptée
  • Chemins de sauvegarde variables selon les machines → variables Ansible
  • Vérification intégrité → ajout checksum MD5 dans les scripts
// Analyse réflexive

Ce projet m'a permis de découvrir la puissance de l'automatisation avec Ansible. J'ai compris l'importance de l'idempotence dans les playbooks et la nécessité de tester les restaurations autant que les sauvegardes. Ce projet a renforcé ma capacité à anticiper les scénarios de panne et à concevoir des solutions robustes.

Projet réseau informatique — Architecture & Services

Conception et déploiement d'une infrastructure réseau complète intégrant Active Directory, DNS redondant, routage dynamique RIP/OSPF, DHCP, RADIUS et messagerie sous VMware.

Active Directory DNS redondant VMware RIP / OSPF DHCP RADIUS Messagerie Grafana
Voir le détail ↓ 2024 · IUT de Roanne

Ce que j'ai réalisé

  • Schéma IP avec subnetting optimisé
  • Active Directory Domain Services + gestion des accès
  • DNS redondant (primaire/secondaire) sous VMware
  • Hébergement site web local (tests & intranet)
  • Routage dynamique RIP et OSPF
  • DHCP pour attribution automatique des adresses
  • Mise en service RADIUS + solution de messagerie
  • Supervision des performances via Grafana/Zabbix

Compétences mobilisées

  • Conception d'architecture réseau multi-services
  • Administration Windows Server & Linux
  • Virtualisation VMware
  • Protocoles réseau avancés (RIP, OSPF, RADIUS)

  • Monitoring & tableaux de bord
